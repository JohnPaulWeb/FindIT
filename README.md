# FindIT

FindIT is a browser-based lost and found bulletin board for the campus community.

## Run the project

Open `Default/index.html` in a modern browser. No server, database, or installation is required.

## Included wireframe

The page follows the proposed wireframe:

- Left column: **Add New Post** form
- Right column: **Search and Filters** plus the community post cards
- Lower section: three-step workflow explaining how the board works

Posts are saved in the browser's `localStorage`, so they remain after refreshing the page on the same browser and device.
